# Empresa

**Nome:** Escala Hotel Titanic (Unificada)
**Negócio:** Web app de escala de trabalho, horários e folgas
**O que faz:** Organização e consulta de escalas por setor (Governança/Camareiras e Recepção/Geral) com login inteligente por senha
**Perfil:** Solopreneur / Criador solo
**Atende clientes:** Gratuito (aplicação web utilitária interna sem cobrança)
**Equipe:** Sozinho
**Ferramentas:** Web app (Node.js, Vercel)
**Principais entregas:** Escalas semanais organizadas por departamento, links públicos para funcionários, exportações em PNG e PDF

## Contexto adicional
App unificado hospedado na Vercel (https://folhaht.vercel.app/) integrado com repositório GitHub vemprapenedorj/folha.
